Death Road to Canada · 作弊 Trainer（脚本版）

一、安装
1. 先关闭游戏。
2. 双击 install.bat。
3. 看到 Installed: 字样即成功（会自动把存档备份到 backup\）。
4. 装好后要重新启动一次游戏才生效。

二、启动面板
1. 先通过 Steam 启动游戏，等进入主菜单。
2. 双击 启动面板.bat。
3. 面板顶部显示"已连接 DR2C 窗口"后，勾选功能即可。
4. 面板不开也能用：在游戏里直接按 Ctrl+0~Ctrl+3，其余功能走面板按钮。

说明：脚本版在内存里编译界面。从网络下载的脚本可能被系统提示“不受信任”，双击 解除锁定.bat 处理即可。
若双击 启动面板.bat 没反应，右键 → 以管理员身份运行。

三、热键表

Ctrl+0  一键全开：资源、回血、武器不坏、不耗体力+清疲劳、一击必杀、士气、载具耐久（不含佐博点）
Ctrl+1  无限资源：食物/汽油/医疗包补到 500，子弹/霰弹/步枪弹补到 300
Ctrl+2  全队回满血
Ctrl+3  载具耐久：底盘和引擎一起锁满（撞车/撞路障/行驶磨损都不掉）

Ctrl+4~Ctrl+9 全部空出来，留给以后的重要功能；Ctrl+9 仍是游戏自带调试控制台。
Ctrl+0 不含佐博点；佐博点只在面板「佐博点 +999」按钮里，点一次加一次。
以下功能没有热键，只在面板上以按钮形式提供：
  武器永不损坏 / 不耗体力+清疲劳 / 一击必杀 / 全体士气拉满
  底盘：开/关、引擎：开/关（单独开关）
  佐博点+999、一键全开、全部停止
面板按钮通过游戏自带控制台执行，点击时控制台会短暂出现，属正常现象。
勾选项（资源/回血/载具）会自动保持；按钮点一次执行一次，换武器后再点一次。
佐博点存在全局统计存档里，只由面板按钮写入 gstats.save，安装时已备份。

四、卸载
1. 先关闭游戏。
2. 双击 uninstall.bat，删除 deathforth\hack\，游戏立即回到原版。
3. 本工具不改流程存档；唯一例外是佐博点按钮会写全局统计存档。如需恢复安装前状态，从 backup\ 把 gstats.save 拷回即可。
