Death Road to Canada · 作弊 Trainer（脚本版）

一、安装
1. 先关闭游戏。
2. 双击 install.bat。
3. 看到 Installed: 字样即成功（会自动把存档备份到 backup\）。
4. 装好后要重新启动一次游戏才生效。

二、启动面板
1. 先通过 Steam 启动游戏，等进入主菜单。
2. 双击 启动面板.bat。
3. 面板顶部显示"已连接 DR2C 窗口"后，勾选功能即可。
4. 面板不开也能用：在游戏里直接按 Ctrl+1..6，Ctrl+0 为全部。

说明：脚本版在内存里编译界面。从网络下载的脚本可能被系统提示“不受信任”，双击 解除锁定.bat 处理即可。
若双击 启动面板.bat 没反应，右键 → 以管理员身份运行。

三、热键表

Ctrl+1  无限资源：食物/汽油/医疗包补到 500，子弹/霰弹/步枪弹补到 300
Ctrl+2  全队回满血
Ctrl+3  武器永不损坏
Ctrl+4  挥武器不耗体力
Ctrl+5  一击必杀
Ctrl+6  载具无限耐久：底盘和引擎都锁满（撞车/撞路障/行驶磨损都不掉）
Ctrl+0  一键全开（依次执行上面六项）

以上都是幂等设置，可反复按；换武器后再按一次即可。
Ctrl+6 是开关：第一次按开启，再按一次关闭。
（小底盘车开启时会把耐久上限抬到 8，避免被一次撞击直接撞毁）

四、卸载
1. 先关闭游戏。
2. 双击 uninstall.bat，删除 deathforth\hack\，游戏立即回到原版。
3. 本工具不改存档；如需恢复安装前的存档，从 backup\ 里拷回即可。
